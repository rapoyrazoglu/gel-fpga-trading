# MMX data plane — RTL

VHDL-2008, one 250 MHz clock, synchronous active-high reset.

```
mac_udp_rx ─▶ feed_parser ─▶ order_book ─▶ pricing_engine_beh ─▶ quote_decider ─▶ order_encoder
                   │                              ▲                    ▲
                   └─▶ inventory_counter ─────────┴────────────────────┤
                                       param_block_loader ─────────────┘
```

| File | Role |
|---|---|
| `mmx_pkg.vhd`, `mmx_multi_pkg.vhd` | Shared types |
| `mac_udp_rx.vhd` | Strips Ethernet, IP and UDP headers |
| `feed_parser.vhd` | Market-data message decode |
| `order_book.vhd` | Small two-sided book: mid, spread, imbalance |
| `inventory_counter.vhd` | Signed, saturating inventory from fills |
| `pricing_engine_beh.vhd` | Five-stage mirror of the C++ `compute_quote` |
| `quote_decider.vhd` | Place, cancel or replace |
| `order_encoder.vhd`, `ouch_encoder.vhd` | Order frame builders |
| `param_block_loader.vhd` | Parameter load, staleness, HMAC |
| `sha256_core.vhd`, `hmac_verify.vhd` | SHA-256 and HMAC verification |
| `obi_skew.vhd`, `vol_ewma.vhd`, `circuit_breaker_hw.vhd` | Smart-pricing blocks |
| `pricing_engine_multi.vhd` | Four parallel pricing lanes |
| `hw_backtester.vhd`, `hw_backtester_wrap.vhd` | On-chip tick replay and PnL |
| `mmx_dataplane.vhd` | Top level |
| `tb_*.vhd` | Self-checking testbenches |
| `tb_*_l2.vhd` | Mutation testbenches; their targets are in [`mutants/`](mutants/) |
| `pricing_vectors.txt` | 500 vectors generated by the C++ reference |

Run everything with `tools/run_offline_regression.sh` from the repository
root. `build_sim.tcl` is the equivalent flow for Vivado's simulator.

The custom-logic wrapper that puts this on an AWS F2 instance is in
[`../cl_dataplane/`](../cl_dataplane/). History and per-testbench results are in
[`PHASE_B_STATUS.md`](PHASE_B_STATUS.md).

The silicon build does not instantiate the HMAC check; see
[timing closure](../../../docs/explanation/timing-closure.md).
